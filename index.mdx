Welcome to the documentation for **DDLC for Android** — an unofficial port of Team Salvato's *Doki Doki Literature Club!* visual novel to Android devices. This project packages the full Ren'Py-based game as a native Android APK, with fixes for touch input, dialog box sizing, `.chr` file handling, and mobile save management.

<Warning>
  This repository may contain spoilers, including in file names. Proceed with caution if you haven't finished the game.
</Warning>

## Quick Start

<Steps>
  <Step title="Check compatibility">
    Make sure your device runs **Android 4.0 (API 14) or higher** and has landscape orientation enabled.
  </Step>
  <Step title="Download the APK">
    Grab the latest release from [GitHub Releases](https://github.com/saber-nyan/ddlc-android/releases/latest) and allow installation from unknown sources in your device settings.
  </Step>
  <Step title="Install and play">
    Open the downloaded `.apk` file, tap **Install**, then launch **DDLC!** from your app drawer.
  </Step>
</Steps>

<Note>
  The developer of the original game is [against fan ports](http://teamsalvato.com/ip-guidelines/) (see the "Fan Games" section). This project is a work in progress and not an official release.
</Note>
